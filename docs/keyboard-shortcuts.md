# SmsHks keyboard shortcuts

## جهات الاتصال
- `Delete`: حذف جهات الاتصال المحددة بعد رسالة التأكيد.
- `Ctrl+A`: تحديد كل جهات الاتصال الظاهرة في الجدول.
- `Ctrl+F`: الانتقال مباشرة إلى مربع البحث.
- `F2`: تعديل جهة اتصال واحدة محددة.

## التقارير
- `Ctrl+F`: الانتقال إلى البحث.
- `Ctrl+A`: تحديد محتويات الجدول الظاهرة.

## عام
- `Ctrl+N`: فتح رسالة جديدة.
- `F5`: تحديث الصفحة الحالية.
